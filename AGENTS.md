# Project Instructions

- This project is a Java web service built with Spring Boot. It exposes website functionality and APIs.
- Write unit tests for new behavior and for behavior changed by a code change. Use JUnit Jupiter.
- Prefer real collaborators or simple test fakes in unit tests. Avoid mocks by default; use Mockito only when a dependency is difficult, expensive, nondeterministic, or impractical to use directly in a unit test. Mock at system boundaries rather than mocking simple data objects or the code under test.
